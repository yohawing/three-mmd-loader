通常の`ThreeMmdLoader`は、MMD用マテリアルと輪郭線・描画順の補助メッシュを作ります。シーンへ追加するのは`model.root`です。`model.mesh`だけを追加すると補助メッシュを含められません。

## マテリアルの役割

| 要素 | 見た目への影響 |
| --- | --- |
| 通常テクスチャ | 材質の色や模様 |
| Toonテクスチャ | ライト方向に応じた明暗の段階 |
| スフィアマップ | 法線方向に応じて加算・乗算などで加える模様 |
| 材質モーフ | 色、透明度、テクスチャ係数などのアニメーション |

共有Toon画像はパッケージに含まれます。通常テクスチャはMMDのUVに合わせて繰り返し、Toonのグラデーションは端を固定して扱います。

## 輪郭線と透過を調整する

輪郭線が不要なら`loader.loadModel(url, { outline: false })`を指定します。描画順プロキシは`materialRenderOrder: false`で無効化できますが、半透明材質の重なり方が変わるため、見た目を確認して使います。

透過判定は材質の不透明度やフラグを基準にします。テクスチャに透明な余白があるだけでは、メッシュ全体が半透明になるとは限りません。UVが使う範囲を考慮したアルファ検査が必要なモデルには、ローダー生成時に`geometryAwareAlpha: true`を指定します。追加の画像検査が発生するため、一律に有効化する前に`model.diagnostics.materials`で判定を確認します。

## 影を設定する

通常のWebGL経路では、レンダラーのシャドウマップ、ライト、モデルの影フラグを揃えます。MMD向けライト設定には`configureMmdSelfShadowDirectionalLight()`、影カメラの範囲調整には`fitMmdSelfShadowDirectionalLightToBox()`を使えます。影の範囲がモデルから外れると欠けるため、まず静止状態で確認します。

TSL経路では専用のセルフシャドウ処理をパイプラインが管理します。[WebGPU / TSL](/guides/webgpu)の構成を使い、通常経路の設定をそのまま重ねないようにします。各ヘルパーの引数は[Three.js API](/api/three)を参照してください。
