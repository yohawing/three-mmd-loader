MMD特有のToon表現、輪郭線（エッジ）、半透明材質の重なり、セルフシャドウを調整するには、モデル読み込み時のオプションと影ヘルパーを組み合わせます。通常のWebGL経路では、`ThreeMmdLoader`がMMD用マテリアルに加えて輪郭線と描画順のプロキシメッシュを作成します。

シーンへ追加するのは`model.root`です。`model.mesh`だけを追加すると、プロキシメッシュが含まれず正しく描画されません。詳しくは[MMDの仕組み](/concepts/how-mmd-works)を参照してください。

## マテリアルの役割

| 要素 | 見た目への影響 |
| --- | --- |
| 通常テクスチャ | 材質の色や模様 |
| Toonテクスチャ | ライト方向に応じた明暗の段階 |
| スフィアマップ | 法線方向に応じて加算・乗算などで加える模様 |
| 材質モーフ | 色、透明度、テクスチャ係数などのアニメーション |

共有Toon画像はパッケージに含まれています。通常テクスチャはMMDのUVに合わせて繰り返し、Toonのグラデーションは端を固定して扱います。

## 輪郭線と透過を調整する

輪郭線が不要なら、`loader.loadModel(url, { outline: false })`で無効化できます。描画順プロキシも`materialRenderOrder: false`で無効化できますが、半透明材質の重なり方が変わるため、実際の表示を見比べて判断してください。

透過判定は材質の不透明度やPMXフラグを基準にします。テクスチャに透明な余白があるだけでは、メッシュ全体が半透明になるとは限りません。

UVが使う範囲を考慮したアルファ検査が必要なモデルには、ローダー生成時に`geometryAwareAlpha: true`を指定できます。追加の画像検査が発生するため、一律に有効化する前に`model.diagnostics.materials`で各材質の判定結果を確かめてください。

## 影を設定する

通常のWebGL経路では、レンダラーのシャドウマップ、ライト、モデルの影フラグをそろえる必要があります。影カメラの範囲がモデルから外れると影が欠けるため、まず静止ポーズで範囲を合わせてください。

- ライトの影設定：`configureMmdSelfShadowDirectionalLight()`
- 影カメラの範囲調整：`fitMmdSelfShadowDirectionalLightToBox()`

TSL経路では専用のセルフシャドウ処理をパイプラインが管理します。[WebGPU / TSL](/guides/webgpu)の構成を使い、通常経路の影設定をそのまま重ねないでください。各ヘルパーの引数は、[Three.jsヘルパー](/api/three)を参照してください。
