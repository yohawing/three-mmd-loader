再現できる不具合報告の書き方と、リポジトリへ変更を提案する手順をまとめています。不具合報告は同じ入力で同じ症状を再現できる形にし、改善提案ではどの作業をどう変えたいかを書いてください。

## 不具合を報告する

報告には次の情報を含めてください。

- ライブラリとThree.jsのバージョン、ブラウザー、OS、GPU、描画経路。
- 再現手順、期待した結果、実際の結果、問題が起きる再生時刻。
- コンソールのエラー、必要な診断情報、最小のコード例。

アセットを添付する場合は、再配布の許可があるかを必ず確かめてください。配布できない場合は公開配布元と再現条件を示すか、同じ症状が出る最小アセットを作ります。ローカルの絶対パスや個人情報は報告から除いてください。

## 変更を送る

[開発ガイド](/project/development)に従って環境を用意し、変更した振る舞いを検証してください。PRには問題、変更後の動作、実行した検証と未実行の範囲を記載します。描画変更では同じ条件の比較画像を添えると確認しやすくなります。

公開APIの利用例や設定が変わる場合は、該当するガイドもあわせて更新してください。生成されたAPIページは直接編集せず、ソースのコメントや型を直して再生成します。
