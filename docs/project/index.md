不具合報告、変更提案、ソースからのビルド、リリース方針など、プロジェクトの開発と運用に関する情報をまとめています。

- [コントリビュートする](/project/contributing)：再現手順と検証結果を添えて不具合報告や変更を提案する方法。
- [開発ガイド](/project/development)：ソースからライブラリとドキュメントをビルドして検証する手順。
- [リリース方針](/project/release-policy)：更新時に確かめる情報と公開物の範囲。

ライブラリをアプリケーションへ導入する場合は、[はじめに](/getting-started)へ進んでください。
