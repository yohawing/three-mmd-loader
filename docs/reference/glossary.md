MMDおよびthree-mmd-loaderのドキュメント全体で使われる主要な用語の意味をまとめています。各概念が1フレームの中でどうつながるかは、[MMDの仕組み](/concepts/how-mmd-works)を参照してください。

## ファイルとデータ

| 用語 | 意味 |
| --- | --- |
| PMX / PMD | 頂点、ボーン、材質などを格納するMMDモデル形式 |
| VMD | ボーン、モーフ、カメラなどのキーフレームを格納するモーション形式 |
| VPD | ボーンの静止ポーズを格納する形式 |
| PMM | モデル参照やタイムラインなどを格納するプロジェクト形式 |
| アクセサリ | DirectX `.x`やVACで表される小物・背景などのデータ |

## 変形と描画

| 用語 | 意味 |
| --- | --- |
| スキニング | ボーンの動きと頂点のウェイトからメッシュを変形する処理 |
| モーフ | 表情や頂点、材質などをウェイトに応じて変える仕組み |
| IK | 目標位置に近づくようにボーン列の回転を求める処理 |
| 付与変形 | 別ボーンの移動や回転を指定割合で受け取る仕組み |
| 材質 / マテリアル | PMX上の定義を材質、Three.js側の描画オブジェクトをマテリアルと呼ぶ |
| Toon | 明暗を段階的に表す材質表現 |
| スフィアマップ | 法線方向に応じて材質へ加算・乗算などで反映するテクスチャ |
| 輪郭線（エッジ） | メッシュの外周に沿って描く線の表現 |
| セルフシャドウ | モデルなどの遮蔽物が落とす影を表面へ反映する処理 |
| TSL | Three.jsのノードを使ってシェーダーを構成する仕組み |

## 物理と実行時の概念

| 用語 | 意味 |
| --- | --- |
| 剛体 | 物理演算で衝突や重力計算の対象になる立体 |
| ジョイント | 二つの剛体を結び、可動範囲やばねの制約を与える要素 |
| ランタイム | 再生時刻からボーン、モーフ、物理などの状態を評価する処理 |
| バックエンド | 共通のインターフェイスを通して差し替える実装。物理ではBulletなど |
| 同期 | 評価済みの状態をThree.jsのメッシュやマテリアルへ反映する処理 |
| パイプライン | マテリアル、モーフ、影、描画の呼び出しをまとめた構成 |
| プロキシメッシュ | 輪郭線や描画順のために追加する補助メッシュ |
| 絶対秒 | モーションの先頭を0とする再生位置。前フレームからの差分時間とは異なる |
