---
title: 対応形式
description: 解析とモデル表示・再生の対応範囲を区別します。
---

各MMDファイル形式について、解析できる範囲とモデル表示・再生で対応する範囲の違いを一覧にまとめています。

| 形式 | 読み込み口 | 対応範囲 |
| --- | --- | --- |
| PMX | `loadModel()` | モデル表示、ボーン、モーフ、材質、剛体・ジョイントの物理接続 |
| PMD | `loadModel()` | モデル表示とモーション適用 |
| VMD | `loadAnimation()` | ボーン、モーフ、カメラ、ライトなどのアニメーション |
| VPD | `loadPose()` / `loadPoseAnimation()` | 静止ポーズの解析とモデルへの適用 |
| PMM | `parsePmmDocument()`など | プロジェクト情報、参照アセット、トラックなどの構造化解析 |
| DirectX `.x` / VAC | `parseAccessory()` | アクセサリや配置設定の構造化解析 |

PMXのスキニングは、BDEF1/2/4に加えてSDEFとQDEFに対応しています。PMXのソフトボディはデータ解析の対象ですが、ランタイムのシミュレーションには対応していません。

VMDのボーン名とモーフ名は、モデル内の名前へ対応付けられます。別モデル用のモーションでは、名前が一致しない一部のキーが適用されない場合があります。カメラとライトはモデルのメッシュを動かすキーではなく、[アニメーション、カメラ、ライト](/guides/animation-camera-light)で紹介するヘルパーで反映する状態です。文字コードや照合の仕組みは、[MMDの仕組み](/concepts/how-mmd-works)を参照してください。

PMMやアクセサリ形式（`.x`、VAC）には、`loadModel()`によるシーン一括再生の経路がありません。解析結果からアセットを解決し、表示や再生を組み立てる処理は呼び出し側で用意します。解析APIの入口は、[Parser API](/api/parser)を参照してください。
