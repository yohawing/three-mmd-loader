---
title: 対応形式
description: 解析とモデル表示・再生の対応範囲を区別します。
---

解析APIがある形式でも、ファイルを渡すだけでシーン全体が再現されるとは限りません。

| 形式 | 読み込み口 | 対応範囲 |
| --- | --- | --- |
| PMX | `loadModel()` | モデル表示、ボーン、モーフ、材質、剛体・ジョイントの物理接続 |
| PMD | `loadModel()` | モデル表示とモーション適用 |
| VMD | `loadAnimation()` | ボーン、モーフ、カメラ、ライトなどのアニメーション |
| VPD | `loadPose()` / `loadPoseAnimation()` | 静止ポーズの解析とモデルへの適用 |
| PMM | `parsePmmDocument()`など | プロジェクト情報、参照アセット、トラックなどの構造化解析 |
| DirectX `.x` / VAC | `parseAccessory()` | アクセサリや配置設定の構造化解析 |

PMXのスキニングはBDEF1/2/4、SDEF、QDEFを扱います。PMXソフトボディはデータ解析の対象ですが、ランタイムのシミュレーションには対応していません。

VMDのボーン名・モーフ名はモデル内の名前へ対応付けます。別モデル用のモーションでは、一部のキーが適用されない場合があります。カメラとライトはモデルのメッシュを動かすキーではなく、[ヘルパーで反映](/guides/animation-camera-light)する状態です。

PMM、`.x`、VACには`ThreeMmdLoader.loadModel()`でのシーン一括再生経路はありません。解析結果からアセットを解決し、表示や再生を組み立てる処理は呼び出し側で用意します。詳細は[Parser API](/api/parser)を参照してください。
