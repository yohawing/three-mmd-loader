---
title: トラブルシューティング
description: 症状から確認箇所と対処を探します。
---

モデル表示や再生で問題が起きたときに、症状から最初に調べる箇所と対処法を探せます。

まずブラウザーの開発者ツールでコンソールとネットワークパネルを開き、最初のエラーから追ってください。設定を一つずつ変えて原因を絞る手順は[デバッグ](/guides/debugging)を、誤った書き方の具体例は[よくある間違い](/concepts/common-pitfalls)を参照してください。

手元のモデル自体が読み込めるかを先に切り分けたい場合は、[Live demo](https://three.mmd.yohawing.com/)のフォルダー読み込みで再現するかを試すこともできます。

| 症状 | 最初に調べる箇所 | 対処 |
| --- | --- | --- |
| モデルの読み込みが失敗する | URL、HTTPステータス、応答の実データ | モデルをHTTP配信し、HTMLへのフォールバックやCORSエラーを直す |
| テクスチャが欠ける | `model.diagnostics.textures`、相対パス、大文字小文字 | フォルダー構造を保ち、ローカルファイルには`textureMap`を渡す |
| モデルが見えない | `model.root`、カメラの位置、ライト | `model.root`を追加し、モデルの高さへカメラを向け、ライトを置く |
| モデルが動かない | VMDのボーン名、`setAnimation()`、更新時刻 | モデル用VMDを設定し、経過秒数を更新する |
| 再生が極端に遅い・先へ進まない | `update()`に渡す数値 | 差分秒ではなくモーション先頭からの絶対秒を渡す |
| カメラVMDが反映されない | `cameraState()`と描画カメラ | ヘルパーが返したカメラで描画する |
| 髪や衣装が揺れない | 物理設定、モデル内の剛体・ジョイント | `physics: "external"`とバックエンドを設定する |
| Bulletの読み込みが失敗する | JSとWASMのURL、ブラウザー環境 | 両ファイルを配信し、必要なら`scriptUrl`を指定する |
| TSLの初期化がWebGPU必須エラーで止まる | 実際のレンダラーバックエンド | WebGPUを有効にするか、通常のWebGL経路を使う |
| Workerの起動が失敗する | Worker内のimport解決、JS・WASMの配信 | Worker用に依存をバンドルするかURLへ変換する |
| TSLでボーン数エラーになる | エラーに表示されるGPU上限 | 通常の`WebGLRenderer`へ切り替える |
| Workerで指定フレームの画像がずれる | 非同期応答の完了 | `await model.updateAsync(seconds)`の後に描画する |
| モデル切り替え後にメモリが増える | 古いモデル、テクスチャ、Workerの寿命 | 更新対象から外し、モデルと所有リソースを破棄する |

半透明材質の重なりや影だけがおかしい場合は、[描画とマテリアル](/guides/rendering)の設定を見直してください。物理のシーク後だけ形が変わる場合は、同じ初期状態から同じ時間刻みで再生して比較します。

解消しない場合は、[コントリビュートする](/project/contributing)に記載した報告項目を添えて再現手順を共有してください。
